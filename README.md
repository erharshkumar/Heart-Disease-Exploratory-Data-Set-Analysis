# Heart-Disease-Exploratory-Data-Set-Analysis
Exploratory Data Analysis on the Heart Disease dataset (918 records, 12 features). Covers distribution plots, correlation heatmap, violin plots, and pairplots using Python, Pandas, and Seaborn. Built to uncover key patterns linked to cardiovascular risk factors like age, cholesterol, and chest pain type.

## 📌 About This Project

This notebook performs Exploratory Data Analysis (EDA) on the Heart Disease dataset 
sourced from Kaggle (918 rows, 12 features).

### What I Did:
- Loaded and inspected the dataset using Pandas
- Plotted distributions of numeric features (Age, Cholesterol, RestingBP, MaxHR, Oldpeak)
- Created pie charts for all categorical features (Sex, ChestPainType, RestingECG, etc.)
- Used violin plots to compare feature distributions across HeartDisease classes
- Generated a correlation heatmap to identify relationships between variables
- Built jointplots and a pairplot for multivariate visual analysis

### Tools & Libraries:
Python | Pandas | NumPy | Seaborn | Matplotlib

### Dataset:
[Heart Failure Prediction Dataset – Kaggle](https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction)
